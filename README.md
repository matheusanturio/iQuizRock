# Quiz Rock - Um App de Perguntas e Respostas sobre Rock'n'Roll 🎸

Este projeto é o resultado do meu aprendizado no curso **[iOS: Construindo seu primeiro aplicativo](https://cursos.alura.com.br/course/ios-construindo-primeiro-aplicativo)** da Alura. A proposta inicial de criar um app de quiz foi expandida e personalizada para o universo do Rock'n'Roll, com perguntas geradas com o auxílio de Inteligência Artificial.

O aplicativo desafia o usuário com uma série de perguntas sobre bandas, músicas e a história do rock, computando a pontuação final com base nas respostas corretas.

## Visão Geral do App

![](https://github.com/matheusanturio/iQuizRock/blob/main/coverReadme.png)

## Funcionalidades Principais

*   **Tela de Início:** Apresenta o quiz e um botão para começar.
*   **Tela de Perguntas:** Exibe as perguntas sobre Rock'n'Roll uma a uma, com opções de múltipla escolha.
*   **Tela de Resultado:** Mostra a pontuação final do usuário, indicando o número de acertos.
*   **Navegação Intuitiva:** Fluxo claro entre as três telas principais do aplicativo.
*   **Contagem de Pontos:** Lógica para verificar respostas corretas e calcular o desempenho.

## Conceitos Aprendidos e Aplicados

Durante o desenvolvimento deste aplicativo, pude aplicar e solidificar os seguintes conceitos fundamentais do desenvolvimento iOS com UIKit:

*   **UIKit:** Utilização dos componentes fundamentais para construir a interface do usuário.
*   **Storyboard:** Criação visual das telas e fluxos de navegação.
*   **Constraints & Autolayout:** Implementação de layouts responsivos que se adaptam a diferentes tamanhos de tela.
*   **Navegação entre Telas (Segues):** Configuração da transição entre ViewControllers.
*   **Passagem de Parâmetros entre Telas:** Transferência de dados (como pontuação ou configurações) entre diferentes ViewControllers.
*   **Criação de Modelos (Structs/Classes):** Estruturação dos dados do quiz (perguntas, respostas, etc.) de forma organizada.
*   **Elementos Dinâmicos:** Atualização da interface com base nas interações do usuário e nos dados do quiz.

##  Desafios e Aprendizados Extras

*   **Personalização do Tema:** Adaptar a ideia original do curso para um tema específico (Rock'n'Roll) exigiu pesquisa e criatividade.
*   **Geração de Conteúdo com IA:** A utilização de Inteligência Artificial para criar as perguntas do quiz foi uma exploração interessante, adicionando um toque moderno ao projeto.
*   **Lógica do Quiz:** Implementar a lógica de apresentação das perguntas, verificação das respostas e cálculo da pontuação.

##  Como Executar (Opcional)

Se você quiser clonar e rodar o projeto:

1.  Clone o repositório: `git clone https://github.com/matheusanturio/iQuizRock.git`
2.  Abra o arquivo `iQuizRock.xcodeproj` (ou `.xcworkspace` se houver) no Xcode.
3.  Selecione um simulador ou dispositivo iOS.
4.  Pressione `Cmd+R` para compilar e executar o aplicativo.

*(Nota: Certifique-se de que a versão do Xcode e do Swift são compatíveis).*
