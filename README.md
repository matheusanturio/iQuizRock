# Quiz Rock - Aplicativo de Perguntas sobre o Rock'n'Roll

Desenvolvimento de aplicativo para aprendizado dos conceitos listado, junto ao Curso da Alura [iOS: Construindo seu primeiro aplicativo](https://cursos.alura.com.br/course/ios-construindo-primeiro-aplicativo). 
Com a ideia inicial de criar um App de quiz, utilizei os concenhimentos aprendidos para explorar e estrapolar a proposta personalizando-a. 


### Conceito aprendidos

UIKit

Storyboard

Constraints

Autolayout

Navegação entre telas

Passagem de parâmetros entre telas

Criação de modelos para representar dados

Elementos dinâmicos
